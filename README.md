# Simulador hidráulico de abastecimiento de agua

Proyecto académico desarrollado en Python mediante Streamlit para analizar el comportamiento hidráulico de un sistema de abastecimiento de agua en una vivienda de cuatro niveles.

## Archivos principales

- app.py: contiene la interfaz gráfica y los controles del simulador.
- hidraulica.py: contiene las funciones y los cálculos hidráulicos.
- requirements.txt: contiene las bibliotecas necesarias para ejecutar la aplicación.

## Acceso al simulador

https://simulador-hidraulico-gpdqwduzriustuym8ctqha.streamlit.app/

## Funcionalidades

- Configuración de las dimensiones de la vivienda.
- Análisis de presión y caudal por piso.
- Cálculo de pérdidas de carga en tuberías.
- Evaluación del sistema de bombeo.
- Visualización y exportación de resultados.
